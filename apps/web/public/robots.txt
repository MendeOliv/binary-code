# Policy
# ------
# Public pages are intentionally crawlable by conventional search engines AND by
# AI / answer systems, so that Código Binário can be discovered, referenced and
# cited. Nothing here guarantees indexing, ranking or citation.
#
# A single `User-agent: *` group is used deliberately: under RFC 9309 a crawler
# obeys ONLY the most specific matching group, so adding named groups for
# individual bots would silently drop the `Disallow: /api/` rule for those bots.
#
# `Disallow` only prevents crawling — it is not access control, and it does not
# remove a URL already indexed. The real private surface is the API (protected
# by an admin key, on its own origin); no private route is reachable on this
# host, so there is nothing else here that robots.txt could protect.

User-agent: *
Allow: /
# This host does not serve /api/* as content (the Fastify API lives on its own
# origin). Kept disallowed defensively so a future route cannot leak.
Disallow: /api/

Sitemap: https://codigobinario.it.ao/sitemap.xml
