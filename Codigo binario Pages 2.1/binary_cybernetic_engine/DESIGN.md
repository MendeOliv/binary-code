## Brand & Style

This design system expresses high-tier architectural engineering, sovereign systems development, and advanced artificial intelligence solutions. Built for enterprise decision-makers, technical founders, and systems architects, the personality balances disciplined technical precision with refined executive authority.

The aesthetic philosophy fuses **High-End Technical Minimalism** with **Controlled Cybernetic Brutalism**:
- **Tactical Precision:** Visual styling mirrors mission-critical kernels, IDE syntax, telemetry dashboards, and precision aerospace interfaces.
- **Architectural Calm:** Eliminates superficial glassmorphic blurs and novelty neon glows in favor of ultra-dark matte surfaces, calibrated hairline micro-borders, and disciplined optical contrast.
- **Syntactic Structure:** Content uses programmatic signifiers—inline bracket delimiters (`[...]`), code comment pre-markers (`//`), directory structures (`[/path]`), and structured state labels (`STATUS: OPERATIONAL`).

## Colors

The palette is rooted in an ultra-dark canvas architecture engineered for sustained visual clarity and zero visual fatigue. 

- **Primary (`#00E599`):** Controlled emerald mint. Used intentionally for affirmative actions, active telemetry indicators, execution triggers, and brand focal anchors.
- **Secondary (`#00B4D8`):** Deep cybernetic cyan. Represents diagnostic flows, AI pipeline telemetry, and auxiliary interface vectors.
- **Tertiary (`#10B981`):** Deep synthetic green. Serves as supporting status feedback, stable operational flags, and subdued structural markers.
- **Neutral (`#94A3B8`):** Low-strain structural slate. Balances high legibility with deep atmospheric absorption on canvas `#080C0E`.

Dark mode operates as the native, unyielding substrate. Elevation is achieved via strictly stepped surface lamination (`#080C0E` → `#0B0F12` → `#10171B` → `#162026`), never through wash backgrounds.

## Typography

The typographic tension pairs clean geometric sans-serif displays with high-density technical monospace notation.

- **Headlines (Geist):** Modern, sharp, and commanding. Titles prioritize high typographic density with deliberate negative tracking for an executive, engineered finish.
- **Reading Body (Inter):** Highly legible, neutral workhorse engineered for complex explanations, diagnostic scopes, and system proposals.
- **Labels, Telemetry, and Tags (JetBrains Mono):** The interface's engineering heartbeat. Used exclusively for path notation (`[/sys]`), prefix indicators (`//`), numeric indices (`01`, `02`), metadata key-values (`STATUS: OPERATIONAL`), and CTA wrappers. Monospaced elements are set in uppercase or strict code formatting to ensure systematic alignment.

## Layout & Spacing

Layouts follow a structured **12-column modular grid** on desktop and tablet, collapsing to a unified **4-column tactical grid** on mobile.

- **Rhythm & Grid Alignment:** Gutters are set strictly to `1.5rem` (`24px`), enabling cards and data arrays to lock into crisp horizontal and vertical alignments reminiscent of PCB schematics and control terminals.
- **Section Pacing:** Vertical gaps between functional architectural blocks scale generously (`4rem` to `6rem` desktop, `2.5rem` mobile) to frame dense data modules with pristine negative space.
- **Breakpoints:**
  - `Desktop (Wide)`: ≥ 1280px (12 columns, max content container 1240px, `3rem` canvas margin).
  - `Tablet / Laptop`: 768px – 1279px (8 columns, `2rem` margin).
  - `Mobile`: ≤ 767px (4 columns, `1.25rem` margin, stacked single-column modular cards).

## Elevation & Depth

Visual hierarchy abandons traditional drop shadows in favor of **Tonal Layering**, **Micro-Borders**, and **Specular Edge Gradients**:

- **Layering Model:**
  - `Canvas Layer (L0)`: `#080C0E` — The baseline execution environment.
  - `Base Surface (L1)`: `#0B0F12` — Root layouts, navigation ribbons, side panels.
  - `Elevated Surface (L2)`: `#10171B` — Interactive modules, metric cards, code blocks.
  - `Active Overlay (L3)`: `#162026` — Modals, popovers, dropdown diagnostics.
- **Micro-Borders:** Every surface boundary is defined by a precision `1px` border set to `rgba(255, 255, 255, 0.08)`. Hover and focused states transition cleanly to a localized directional gradient border utilizing `rgba(0, 229, 153, 0.35)`.
- **Specular Glow:** High-priority cards feature an inner edge highlight: a subtle radial glow of `rgba(0, 229, 153, 0.04)` pinned to the top-left corner, giving surfaces a precision-milled matte titanium texture without diffusive blur clutter.

## Shapes

The design system maintains a **Soft Architectural (`1`)** shape geometry.

- **Surfaces & Modules:** Standard containers, capability cards, and data displays use `0.25rem` (`4px`) to `0.5rem` (`8px`) radiuses. This avoids organic softness, preserving the industrial silhouette of technical hardware rack units.
- **Interactive Units:** Buttons, input fields, and telemetry chips share crisp `4px` corners.
- **Syntactic Enclosures:** The system deliberately avoids full pill shapes (`rounded-full`). Instead, technical pill enclosures are simulated typographically using monospace brackets (`[` and `]`) or hard angular corners, preserving the CLI engineering aesthetic.

## Components

### Buttons & Interactive Triggers
- **Primary CTA:** Matte `#00E599` background with deep `#080C0E` high-contrast typography, styled with `label-code` or `headline-sm` tracking. Text is accompanied by monospaced delimiters and directional glyphs: `[START DIAGNOSTIC →]`.
- **Secondary CTA:** Surface `#10171B`, hairline border `1px solid rgba(255,255,255,0.08)`, text `#F1F5F9`. On hover, the border transitions to `#00E599` with text color shift to `#00E599`.
- **Terminal Trigger:** Ghost state with monospace route syntax (e.g., `[/diagnostic]`), highlighted with emerald under-lines on hover.

### Telemetry Badges & Chips
- Compact inline pills with uppercase monospace labels.
- Structure: Status dot (`6px` solid circle with subtle emerald or cyan pulsing glow) + key/value readout: `[STATUS: OPERATIONAL]`.
- Background: `#10171B` with `1px solid rgba(255, 255, 255, 0.08)`.

### Cards & System Modules
- **Construction:** Background `#0B0F12` or `#10171B`, framed with `1px solid rgba(255,255,255,0.08)`.
- **Header Structure:** Includes an index counter (`01`, `02`) in `JetBrains Mono` at the top right, preceded by a functional eyebrow prefix (`// CAPABILITIES`).
- **Footer Specifier:** Technical metadata row anchored to the bottom edge displaying stack details: `STACK // NEXT.TS, TYPESCRIPT, NODE`.

### Input Fields
- Dark matte field `#080C0E` inset inside `#10171B`.
- Border `1px solid rgba(255,255,255,0.12)`.
- Active focus state: Hairline ring in `#00E599` with monospaced prompt prefix indicator (`> ` or `INPUT:`). Placeholder text in `#475569`.

### Selection Controls (Checkboxes & Radios)
- Square geometry (`4px` radius for checkboxes, sharp diamond/rotated squares for radios).
- Inactive: Background `#0B0F12`, border `1px solid rgba(255,255,255,0.2)`.
- Active: Background `#00E599`, checkmark icon in `#080C0E`.

### Data Tables & Telemetry Feeds
- Compact vertical padding (`0.5rem` to `0.75rem`).
- Column headers formatted in `label-telemetry` uppercase.
- Alternating row zebra lines omitted; separation handled strictly via `1px solid rgba(255,255,255,0.04)` horizontal dividers.
