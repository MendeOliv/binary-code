## Brand & Style

This design system establishes a high-performance, authoritative visual language positioned at the intersection of **Terminal Noir**, **Advanced AI Systems Laboratories**, and **Brutalist Digital Architecture**. It is engineered for mission-critical software, sovereign AI telemetry consoles, infrastructure orchestration, and elite technical environments.

### Core Tenets
- **Engineered Precision:** Every element operates on strict dimensional grids. Zero decorative fluff; utility is the aesthetic.
- **Terminal Noir Atmosphere:** Deep abyssal charcoals and navy foundations punctuated by high-potency emerald luminescence, reminiscent of phosphor displays and dark-mode server environments.
- **Architectural Brutalism:** Unforgiving structural borders, hairline grid subdivisions, zero border-radii, and persistent telemetry metadata (`SYSTEM.ONLINE`, `STABLE_KERNEL`, `NODE_SYNC_OK`).
- **Telemetry & Microcopy:** System diagnostics, memory footprints, and command strings replace traditional vague marketing idioms, delivering immediate technical credibility and uncompromised focus.

## Colors

The palette leverages a dark-room, low-reflectance foundation designed to eliminate eye fatigue while providing laser-focused contrast for critical indicators and synthetic intelligence streams.

### Surface System
- **Void Base (`#060D20`):** The absolute deepest canvas tone. Reserved for window backdrops and fullscreen terminals.
- **Surface Layer 1 (`#0B1326`):** Primary panel container, sidebar background, and root viewports.
- **Surface Layer 2 (`#111827`):** Elevated data containers, terminal shells, and inspect panels.
- **Surface Layer 3 (`#171F33`):** Active card modules, interactive inputs, and hover surfaces.
- **Surface Border / Hairline (`#222A3E`):** The definitive architectural boundary for structural framing.

### Luminescent Primaries & Accents
- **Intelligent Emerald (`#4EDEA3`):** Primary interaction point, active cursor status, system health indicators, and high-priority states.
- **Deep Emerald (`#10B981`):** Subdued success states, active secondary indicators, and gradient anchors.
- **Cyan Relay (`#06B6D4`):** Secondary data pipelines, network telemetry, and stream routing.
- **Sapphire Vector (`#3B82F6`):** Standard informational tokens, telemetry metrics, and cold execution links.
- **Amethyst Neural (`#A855F7`):** AI synthesis, autonomous agent nodes, and speculative computation traces.

### Content & Readout
- **Text Light Emerald / Glint (`#D8F3DC`):** High-prominence headers, key value outputs, and focused inputs.
- **Ice Polar (`#DBE2FD`):** Body typography, technical documentation, and primary log feeds.
- **Muted Slate (`#94A3B8`):** Inactive icons, telemetry sub-labels, and hardware IDs.
- **Muted Matrix (`#BBCABF`):** Comment code, metadata brackets, and subtle grid indicators.

## Typography

Typography is treated as structured code output rather than traditional prose. The entire interface operates in **JetBrains Mono** to reinforce the feeling of an operational terminal, compiler, and technical workspace.

### Typographic Principles
- **Case Standardization:** System tags, operational labels, and metadata are strictly uppercase (`ALL_CAPS` or `SNAKE_CASE_UPPERCASE`) with widened tracking (`letterSpacing: 0.08em` to `0.12em`).
- **Tabular Numerics:** All numerals utilize fixed monospace alignment (`font-variant-numeric: tabular-nums`) to prevent layout shifts during live metrics streaming and calculation updates.
- **Editorial Contrast:** Headings achieve emphasis through weight variations (`600`/`700`) and emerald highlight brackets rather than extreme point size jumps, maintaining a compact editorial information density.

## Layout & Spacing

The layout model is anchored by a high-density, architectural modular grid system designed for multi-pane dashboards, telemetry streams, and complex tooling interfaces.

### Grid Architecture
- **Desktop (1280px+):** Strict 12-column or 16-column continuous grid. Gutter: `1.25rem` (20px). Panels butt against hairline containment boundaries (`#222A3E`) creating unified multi-window consoles.
- **Tablet (768px - 1279px):** 8-column layout. Gutter: `1rem` (16px). Secondary toolbars compress into tabbed tool-drawers.
- **Mobile (<768px):** Single-column stacked stream. Gutter: `0.75rem` (12px). Margins: `0.75rem`. Complex data grids reflow into vertical key-value telemetry cards.

### Architectural Alignment
- Interfaces avoid floating, isolated cards. Instead, components lock edge-to-edge with 1px border intersections, mimicking physical hardware server racks and flight instrument arrays.

## Elevation & Depth

This design system rejects skeuomorphic shadows and soft drops in favor of structural contrast, precision outlines, and controlled neon phosphor emission.

### Depth Mechanisms
- **Hairline Framing:** Depth is established primarily via 1px solid structural outlines (`#222A3E`) on top of layered surface tones (`#060D20` → `#0B1326` → `#111827`).
- **Phosphor Bloom (The Emerald Glow):** Focused interactive elements, active compilation nodes, or critical alerts emit a restrained luminescence:
  - Focused Card / Panel: `box-shadow: 0 0 16px -2px rgba(78, 222, 163, 0.15), inset 0 0 0 1px rgba(78, 222, 163, 0.4)`
  - Active Button / Status Ring: `box-shadow: 0 0 12px 0px rgba(78, 222, 163, 0.35)`
- **Z-Index Layering Tiers:**
  - Base Deck (Canvas): `0`
  - System Panels & Framework Tiles: `10`
  - Overlay Headers & Telemetry Strips: `20`
  - Modal Command Palettes / Terminal Overlays: `50`
  - Toast Telemetry & Critical Interrupts: `100`

## Shapes

The shape hierarchy is completely uncompromising: **0px border-radius (`roundedness: 0`) across all elements**.

### Aesthetic Directives
- **Zero Radius:** Buttons, inputs, modals, popovers, badges, and panel frames are strictly rectangular. 
- **Angled Notches (Optional Motif):** Special tactical badges and hero headers may utilize 45-degree chamfered clip-paths (`clip-path: polygon(...)`) to evoke precision hardware machining and futuristic schematic blueprints.
- **Dividers:** Clean, 1px horizontal and vertical hairline vectors. No rounded caps or gradients at border terminators.

## Components

### Buttons
- **Primary Action (Command Execute):**
  - Background: `#4EDEA3` with text in `#060D20` (bold, uppercase).
  - Border: 1px solid `#4EDEA3`.
  - Radius: `0px`.
  - Hover: Background `#10B981`, box-shadow: `0 0 14px rgba(78, 222, 163, 0.4)`.
  - Microcopy convention: Preceded by `>` prompt (e.g., `> INITIALIZE_RUN`, `> DEPLOY.SH`).
- **Secondary / Ghost Action:**
  - Background: `#111827` (or transparent).
  - Border: 1px solid `#222A3E`.
  - Text: `#D8F3DC`.
  - Hover: Border color `#4EDEA3`, background `#171F33`.

### Input Fields & Terminal Consoles
- **Text / Code Inputs:**
  - Background: `#060D20`.
  - Border: 1px solid `#222A3E`.
  - Text: `#D8F3DC`.
  - Placeholder: `#94A3B8`.
  - Active / Focus: Border `#4EDEA3`, subtle glow `0 0 8px rgba(78, 222, 163, 0.2)`. Prefix with terminal prompt indicator `$` or `λ`.

### Badges & Telemetry Chips
- **System Badges:**
  - Compact uppercase typography (`label-sm`).
  - Background: Semi-transparent fill of the respective intent (`rgba(78, 222, 163, 0.08)` for emerald, `rgba(6, 182, 212, 0.08)` for cyan).
  - Border: 1px solid channel color (`#4EDEA3`, `#06B6D4`, `#A855F7`).
  - Leading status indicator: 6px solid square beacon (flashing for live states).
  - Labels: `[SYSTEM.ONLINE]`, `[CPU: 14.2% GFLOPS]`, `[EOF_REACHED]`.

### Cards & Module Containers
- **Architectural Panels:**
  - Background: `#0B1326`.
  - Border: 1px solid `#222A3E`.
  - Header Strip: Darker accent surface `#060D20` with 1px bottom border, carrying panel coordinates (e.g., `// PANEL_01 // SEC_ALPHA`), icon, and window control icons.

### Checkboxes & Binary Radios
- **Checkboxes:**
  - Sharp 14px square.
  - Inactive: `#060D20` background, `#222A3E` border.
  - Checked: Solid `#4EDEA3` fill with high-contrast `#060D20` inner square (no checkmarks; technical solid fill indicator).
- **Radio Inputs:**
  - Sharp nested square (no circles).
  - Selected state manifests as an inner `#4EDEA3` solid pip centered inside a sharp framed box.

### Telemetry Logs & Data Tables
- Continuous horizontal rows separated by 1px `#171F33`.
- Alternating row zebra tone: `rgba(255, 255, 255, 0.01)`.
- Hover state: Row-level highlighting in `#111827` with an emerald 2px left border accent.
